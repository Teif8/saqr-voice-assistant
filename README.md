# صقر | Saqr AI Voice Assistant 🇸🇦

صقر هو مساعد صوتي ذكي عربي مستوحى من الهوية السعودية، يتيح للمستخدم التفاعل بالصوت أو النص للحصول على ردود ذكية باستخدام تقنيات الذكاء الاصطناعي الحديثة.

تم تطوير المشروع ليقدم تجربة تفاعلية عربية بواجهة مستوحاة من الثقافة السعودية، مع دعم التسجيل الصوتي وتحويل النص إلى صوت والردود الذكية.

---

# ✨ Features

- 🎙️ تسجيل صوتي مباشر من المتصفح
- 🤖 ردود ذكية باستخدام الذكاء الاصطناعي
- 🔊 تحويل النص إلى صوت
- 🇸🇦 واجهة مستوحاة من الهوية السعودية
- 💬 واجهة محادثة تفاعلية
- ⚡ أزرار اقتراحات سريعة
- 🌐 دعم اللغة العربية
- 🎨 تصميم حديث وتجربة مستخدم سلسة
